# MID-TERM-PROJECT-BANO-QABIL
# 🌐 Web Hosting Landing Page

A modern, responsive web hosting service landing page built with HTML and CSS featuring smooth animations, gradient effects, and mobile-first design.

---

## 📋 Project Overview

This project was developed as part of our **Mid-Term Project** for our web development course at Bano Qabil. It showcases a fully responsive website for a web hosting service provider with an emphasis on modern UI/UX design principles and clean code structure.

---

## ✨ Features

- 🎨 **Modern UI Design** - Purple gradient theme with smooth animations
- 📱 **Fully Responsive** - Works seamlessly on desktop, tablet, and mobile devices
- 🍔 **Hamburger Menu** - Interactive mobile navigation
- ⚡ **Smooth Animations** - Fade-in effects and hover transitions
- 🎯 **Clean Layout** - Grid-based hero section and footer
- 💅 **Gradient Buttons** - Eye-catching call-to-action buttons
- 🔗 **Navigation Effects** - Animated underline hover effects

---

## 🛠️ Technologies Used

- **HTML5** - Semantic markup structure
- **CSS3** - Advanced styling and animations
- **Flexbox** - Flexible layout system
- **CSS Grid** - Two-dimensional layout
- **Media Queries** - Responsive design implementation

## 🚀 How to Run

1. Clone or download this repository
2. Open `index.html` in your web browser
3. That's it! The website is ready to view

```bash
# Clone the repository (if using Git)
git clone <repository-url>

# Navigate to project folder
cd project-folder

# Open in browser
open index.html
```

---

## 📱 Responsive Breakpoints

- **Desktop**: 1024px and above
- **Tablet**: 768px - 1024px
- **Mobile**: Below 768px
- **Small Mobile**: Below 480px
